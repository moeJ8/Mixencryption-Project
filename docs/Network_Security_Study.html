1. Core security goals: confidentiality, integrity, availability, authenticity 1. الأهداف الأمنية: السرية، التكامل، التوفر، الأصالة

Definitions — read these firstالتعريفات — اقرأها أولاً
Confidentialityالسرية
Unauthorized parties must not read or access protected data; only authorized users see the content.غير المصرح لهم لا يقرأون ولا يصلون للبيانات؛ المصرح لهم فقط يرون المحتوى.
Integrityالتكامل
Data is not changed in an undetectable way; unauthorized modification can be discovered.لا يتغيّر المحتوى دون إمكانية اكتشاف ذلك؛ التعديل غير المصرح يُكتشف.
Availabilityالتوفر
Systems and data are accessible and usable on demand by authorized users.الأنظمة والبيانات متاحة لمن له صلاحية عند الحاجة.
Authenticityالأصالة
You can trust the identity of a user, host, or message (it is not an impostor).يمكنك الوثوق بهوية المستخدم أو الخادم أو الرسالة (ليست منتحلة).
Figures & intuitionأشكال وفهم بصري
Examplesأمثلة
  • Confidentiality: TLS on online banking stops café Wi‑Fi eavesdropping (vs plaintext HTTP on Wireshark).السرية: TLS على البنك يمنع التنصت على شبكة المقهى.
  • Integrity: Compare SHA-256 of downloaded exam.pdf to hash published on site.التكامل: مقارنة هاش الملف المنزّل بهاش الموقع.
  • Availability: Homework server down at deadline due to SYN flood (DoS).التوفر: الخادم معطّل بسبب حرمان الخدمة.
  • Authenticity: TLS certificate proves real university portal vs phishing clone.الأصالة: شهادة TLS تثبت البوابة الحقيقية.
Worked scenarioسيناريو تطبيقي

Hospital shares MRI scans between two sites over the Internet.
• Confidentiality: AES/TLS so scans are not public.
• Integrity: HMAC or signed manifest so a bit flip is detected.
• Availability: redundant links + DDoS filtering so ER can always fetch scans.
• Authenticity: mutual TLS so each site proves its hospital identity. مستشفى يشارك صور MRI بين موقعين عبر الإنترنت.
• السرية: AES/TLS.
• التكامل: HMAC أو قائمة موقّعة.
• التوفر: روابط احتياطية + فلترة DDoS.
• الأصالة: TLS متبادل لإثبات هوية المستشفى.

2. Attacks vs security mechanisms vs security services 2. الفرق بين الهجمات والآليات الأمنية والخدمات الأمنية

Definitions — read these firstالتعريفات — اقرأها أولاً
Security attackهجوم أمني
Any deliberate action that violates a security goal (read secrets, alter data, block service, impersonate).فعل متعمّد يخترق هدفاً أمنياً (سرقة، تعديل، حجب، انتحال).
Security mechanismآلية أمنية
A procedure, tool, or algorithm used to enforce protection (encryption, hash, firewall, TLS, nonce, MAC, signature).إجراء أو أداة أو خوارزمية لفرض الحماية (تشفير، هاش، جدار ناري، TLS، NONCE، MAC، توقيع).
Security serviceخدمة أمنية
The abstract security benefit you need (confidentiality service, integrity service, authentication, non-repudiation, access control). Mechanisms provide services.المنفعة الأمنية المجردة (سرية، تكامل، مصادقة، عدم إنكار، تحكم بالوصول). الآليات تحقّق الخدمات.
Passive attackهجوم سلبي
Attacker observes data or traffic but does not modify systems or messages (eavesdropping, traffic analysis).المهاجم يراقب دون تعديل الأنظمة أو الرسائل (تنصت، تحليل حركة).
Active attackهجوم نشط
Attacker changes, inserts, deletes, or replays data or disrupts systems (MITM, malware, DoS/DDoS).المهاجم يغيّر أو يحقن أو يحذف أو يعيد البيانات أو يعطّل الأنظمة.
Figures & intuitionأشكال وفهم بصري
Passive attackهجوم سلبيActive attackهجوم نشط
Eavesdrop, traffic analysis; bits unchangedتنصت؛ البتات دون تغيير Modify, inject, delete, replay, DoSتعديل، حقن، حذف، إعادة، حرمان
Examplesأمثلة

Mapping attack → mechanism → service: Cookie theft on HTTP (attack) → HTTPS + HttpOnly (mechanism) → confidentiality service. ربط هجوم → آلية → خدمة: سرقة كوكيز على HTTP → HTTPS (آلية) → خدمة سرية.

Exam-style casesحالات بأسلوب الامتحان
  • Passive: competitor counts packet sizes to guess when payroll runs (traffic analysis).سلبي: تحليل أحجام الحزم لتخمين موعد الرواتب.
  • Active: attacker changes a bank transfer amount in a message without TLS/MAC.نشط: تغيير مبلغ تحويل دون TLS/MAC.
  • Replay (active): capture “transfer $10” and send it again — stopped by nonce or timestamp.إعادة تشغيل: إرسال نفس أمر التحويل مرة أخرى — يُوقف بـ NONCE أو وقت.

3. Symmetric vs asymmetric encryption; public & private keys; block vs stream; NONCE 3. التشفير المتماثل وغير المتماثل؛ المفتاح العام والخاص؛ الكتلة والتيار؛ NONCE

Definitions — read these firstالتعريفات — اقرأها أولاً
Symmetric encryptionتشفير متماثل
Same secret key K is used to encrypt and decrypt. Both parties must possess K.نفس المفتاح السري K للتشفير وفك التشفير؛ يجب أن يملكه الطرفان.
Asymmetric (public-key) encryptionتشفير غير متماثل
Uses a key pair: public key (shared) and private key (secret). Data encrypted with one key is decrypted with the other, depending on the operation (encrypt vs sign).يستخدم زوج مفاتيح: عام وخاص؛ التشفير بأحدهما وفك التشفير بالآخر حسب العملية.
Public key (PK)المفتاح العام
Can be published. Others use it to encrypt messages to you or to verify your digital signature.يُنشر؛ يُستخدم لتشفير رسائل إليك أو التحقق من توقيعك.
Private key (SK)المفتاح الخاص
Must stay secret. Used to decrypt messages sent to you and to create digital signatures.يبقى سرياً؛ لفك التشفير ولإنشاء التوقيعات الرقمية.
Block cipherتشفير كتلة
Encrypts fixed-size blocks of plaintext (AES block = 128 bits). Often used with a mode (CBC, GCM).يشفّر كتلاً بحجم ثابت (كتلة AES = 128 بت) غالباً مع وضع تشغيل.
Stream cipherتشفير تيار
Generates a keystream and XORs it with data one bit or byte at a time (e.g., ChaCha20).يولّد تيار مفتاح ويعمل XOR مع البيانات بت/بايت تلو الآخر.
NONCENONCE
Number used once — a fresh, often random value used only once per message/session to prevent replay attacks and to derive unique keys or IVs.رقم يُستخدم مرة واحدة — قيمة جديدة لكل رسالة/جلسة لمنع إعادة التشغيل واشتقاق مفاتيح أو IV فريدة.
Figures & intuitionأشكال وفهم بصري
Examplesأمثلة

Symmetric: AES session key on both phones after setup. Asymmetric: encrypt grade with PKBob, Bob decrypts with SKBob; Alice signs with SKAlice, verify with PKAlice. متماثل: مفتاح جلسة AES. غير متماثل: تشفير بعام بوب، فك بخاصه؛ توقيع بخاص أليس والتحقق بعامها.

Unitالوحدة128-bit blocksكتل 128 بتkeystream XOR 1 byte at a timeتيار مفتاح XOR بايتاً بايت
ExampleمثالAES-GCM on a fileAES-GCM على ملفChaCha20 on a live videoChaCha20 على بث حي

NONCE: login packet carries N=48291 once; replay of old N is rejected.NONCE: طلب دخول بقيمة N جديدة؛ إعادة N القديمة مرفوضة.

4. AES, TRNG, hashes, SHA, concatenation, RSA signatures, tags, MAC 4. AES و TRNG ودوال الهاش و SHA والربط وتوقيع RSA والعلامات و MAC

Definitions — read these firstالتعريفات — اقرأها أولاً
AES (Advanced Encryption Standard)AES
Symmetric block cipher; block size 128 bits; key sizes 128, 192, or 256 bits; rounds 10, 12, or 14 respectively.تشفير متماثل؛ كتلة 128 بت؛ مفاتيح 128 أو 192 أو 256؛ جولات 10 أو 12 أو 14.
AES round phasesمراحل جولة AES
SubBytes (byte substitution), ShiftRows (row shift), MixColumns (column mix; omitted in final round), AddRoundKey (XOR round key).SubBytes، ShiftRows، MixColumns (تُحذف آخر جولة)، AddRoundKey.
TRNGTRNG
True Random Number Generator — randomness from unpredictable physical events (hardware noise). Used when keys must be unguessable.مولد أرقام عشوائية حقيقية من أحداث فيزيائية غير متوقعة للمفاتيح.
Cryptographic hash functionدالة الهاش التشفيرية
Maps input of any length to a fixed-length digest; one-way; collision and preimage resistance (ideal).تحوّل أي مدخل إلى ملخص بطول ثابت؛ اتجاه واحد؛ مقاومة تصادم وأصل.
Concatenation (∥)الربط (∥)
Placing one string immediately after another; order matters when hashing or signing combined fields.وصل سلسلتين؛ الترتيب مهم عند الهاش أو التوقيع.
SHASHA
Secure Hash Algorithm family (SHA-1, SHA-2 such as SHA-256, SHA-3). Produces hash digests of standard sizes.عائلة خوارزميات هاش آمنة (SHA-1، SHA-2 مثل SHA-256، SHA-3).
RSA digital signatureتوقيع RSA الرقمي
Hash the message, sign digest with sender’s private key, verify with sender’s public key.هاش الرسالة، وقّع بالخاص، تحقق بالعام.
Authentication tag (types)علامة مصادقة (أنواع)
(1) MAC/HMAC tag — symmetric; (2) AEAD tag (e.g. GCM); (3) digital signature — asymmetric.(1) MAC/HMAC متماثل؛ (2) علامة AEAD؛ (3) توقيع رقمي غير متماثل.
MAC (Message Authentication Code)MAC
Keyed algorithm providing integrity and authenticity of a message between parties sharing a secret (e.g. HMAC). Not the same as a network MAC address.خوارزمية بمفتاح سري تضمن التكامل والأصالة (مثل HMAC). ليس عنوان MAC للشبكة.
Figures & intuitionأشكال وفهم بصري
Examplesأمثلة
  • TRNG: /dev/random for crypto keys; PRNG must not be used alone for keys unless seeded from TRNG.TRNG للمفاتيح؛ لا PRNG وحده للمفاتيح دون بذرة من TRNG.
  • Concatenation: H("PAY" ∥ amount ∥ acct) ≠ H(amount ∥ "PAY" ∥ acct).الربط: تغيير الترتيب يغيّر الهاش.
  • SHA-256 always outputs 256 bits whether input is 1 byte or 1 GB.SHA-256 تخرج 256 بت دائماً بغض النظر عن حجم المدخل.
MAC vs digital signatureMAC مقابل التوقيع الرقمي

Two roommates share Wi‑Fi password K. They HMAC-SHA256(login requests) so only someone with K can forge valid tags — but either roommate could deny later (no non-repudiation). A university registrar signs PDFs with SKuni; anyone with PKuni can prove the registrar signed — non-repudiation. شريكان يتشاركان K ويستخدمان HMAC — لا إنكار قوي. الجامعة توقّع PDF بمفتاحها الخاص — عدم إنكار.

5. PKI, TLS, and SSH — how they fit together 5. PKI و TLS و SSH — كيف تترابط

Definitions — read these firstالتعريفات — اقرأها أولاً
PKI (Public Key Infrastructure)PKI
Framework of trusted Certificate Authorities (CAs), digital certificates, and policies that bind identities to public keys and manage trust.إطار جهات إصدار شهادات وسياسات تربط الهويات بالمفاتيح العامة وتدير الثقة.
TLS (Transport Layer Security)TLS
Protocol that provides confidentiality and integrity between applications over a transport (usually TCP). Used by HTTPS. Negotiates ciphers and authenticates servers via certificates.بروتوكول سرية وتكامل فوق النقل (غالباً TCP)؛ يُستخدم في HTTPS؛ يتفاوض على التشفير ويصادق الخوادم بالشهادات.
SSH (Secure Shell)SSH
Protocol for secure remote login, command execution, and file transfer over insecure networks (replaces telnet). Encrypts the session; typically port 22.بروتوكول دخول وتنفيذ أوامر ونقل ملفات آمن (بديل telnet)؛ يشفّر الجلسة؛ المنفذ 22 عادةً.
Figures & intuitionأشكال وفهم بصري
Examplesأمثلة
  • PKI: browser validates https://google.com cert chain to trusted root + hostname.PKI: المتصفح يتحقق من سلسلة الشهادة واسم المضيف.
  • TLS: ClientHello → cert → session keys → encrypted HTTP (HTTPS).TLS: مصافحة → مفاتيح جلسة → HTTP مشفّر.
  • SSH: ssh user@host — verify host fingerprint; encrypted terminal (not telnet).SSH: طرفية مشفّرة وتحقق من المضيف.

6. IPv4 address, network address, subnet mask (with worked example) 6. عنوان IPv4 وعنوان الشبكة وقناع الشبكة (مثال محسوب)

Definitions — read these firstالتعريفات — اقرأها أولاً
IPv4 addressعنوان IPv4
A 32-bit logical address for a host or interface, usually written in dotted decimal (four octets, e.g. 192.168.5.102).عنوان منطقي 32 بت للمضيف، يُكتب عادةً بأربعة أوكتتات عشرية.
Subnet maskقناع الشبكة
32-bit value (or prefix length /n) that separates the address into network bits (prefix) and host bits. Example: 255.255.255.0 = /24.قيمة 32 بت (أو بادئة /n) تفصل بتات الشبكة عن بتات المضيف.
Network addressعنوان الشبكة
The address of the subnet itself: IP AND mask with all host bits set to 0 (identifies the network).عنوان الشبكة: IP AND القناع مع جعل بتات المضيف أصفاراً.
Broadcast addressعنوان البث
Address with all host bits set to 1 — sends to every host on the subnet.عنوان بكل بتات المضيف = 1 للبث لجميع المضيفات في الشبكة.
Figures & intuitionأشكال وفهم بصري
Worked exampleمثال محسوب

Given: IP = 192.168.5.102, mask = 255.255.255.0 (/24).
• Network = 192.168.5.102 AND 255.255.255.0 = 192.168.5.0
• Broadcast = host bits all 1 → 192.168.5.255
• Usable hosts: 192.168.5.1 – 192.168.5.254 (28 − 2 = 254) معطى: IP = 192.168.5.102، القناع /24.
• الشبكة = 192.168.5.0
• البث = 192.168.5.255
• المضيفات: .1 – .254 (254 مضيفاً)

Security use of subnettingالأمن وتجزئة الشبكة

Put student lab PCs on 10.10.20.0/24 and payment servers on 10.10.30.0/24. Firewall rule: deny all from 10.10.20.0/24 → 10.10.30.0/24. Even if a lab PC is compromised, it cannot reach the payment VLAN — defense in depth using addresses + ACLs. معاملات الطلاب في شبكة ومخدمات الدفع في أخرى؛ الجدار الناري يمنع الوصول بينهما حتى لو اُخترق جهاز معمل.
