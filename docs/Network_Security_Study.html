1. Core security goals: confidentiality, integrity, availability, authenticity 1. الأهداف الأمنية: السرية، التكامل، التوفر، الأصالة

Confidentiality keeps information secret from unauthorized parties. Mechanisms include encryption, access control, and steganography. Breaches include eavesdropping and stolen credentials. السرية تبقي المعلومات بعيدة عن غير المصرح لهم. تشمل الآليات التشفير والتحكم بالوصول والإخفاء. الانتهاكات تشمل التنصت وسرقة بيانات الدخول.

Integrity ensures data and systems are not altered without detection. Use hashes, MACs, and digital signatures. Attacks include tampering, malware that changes files, and MITM modification. التكامل يضمن عدم تغيير البيانات والأنظمة دون اكتشاف. استخدم الهاش و MAC والتوقيعات الرقمية. الهجمات تشمل التلاعب وبرمجيات تغيّر الملفات وتعديل رجل في الوسط.

Availability means authorized users can access services when needed. Protect with redundancy, filtering, and rate limits. DoS/DDoS and ransomware that locks systems target availability. التوفر يعني أن المستخدمين المصرح لهم يصلون للخدمات عند الحاجة. الحماية بالتكرار والفلترة وحدود المعدل. DoS/DDoS وبرمجيات الفدية تستهدف التوفر.

Authenticity (authentication) proves identity — who sent a message or who logged in. Passwords, MFA, certificates, and digital signatures support authenticity. Often paired with integrity (you trust both the sender and the content). الأصالة (المصادقة) تثبت الهوية — من أرسل الرسالة أو من سجّل الدخول. كلمات المرور والمصادقة متعددة العوامل والشهادات والتوقيعات تدعم الأصالة. غالباً تُقرن بالتكامل (تثق بالمرسل والمحتوى).

2. Attacks vs security mechanisms vs security services 2. الفرق بين الهجمات والآليات الأمنية والخدمات الأمنية

Security attack: Any action that compromises a security goal (read secret data, change data, block access, impersonate a user). هجوم أمني: أي فعل يخترق هدفاً أمنياً (قراءة سرية، تغيير بيانات، حجب وصول، انتحال مستخدم).

Security mechanism: A procedure or algorithm that enforces protection — encryption, hashing, digital signatures, access control lists, firewalls, nonces, MAC, TLS. آلية أمنية: إجراء أو خوارزمية تفرض الحماية — تشفير، هاش، توقيعات، قوائم تحكم، جدران نارية، NONCE، MAC، TLS.

Security service: The abstract benefit you want — confidentiality service, integrity service, authentication service, non-repudiation, access control. Mechanisms implement services. خدمة أمنية: المنفعة المجردة المطلوبة — سرية، تكامل، مصادقة، عدم إنكار، تحكم بالوصول. الآليات تحقق الخدمات.

3. Symmetric vs asymmetric encryption; public & private keys 3. التشفير المتماثل وغير المتماثل؛ المفتاح العام والخاص

Symmetric: One shared secret key K for encrypt and decrypt. Fast (AES). Challenge: secure key distribution. متماثل: مفتاح سري مشترك K للتشفير وفك التشفير. سريع (AES). التحدي: توزيع المفتاح بأمان.

Asymmetric (public-key): Key pair — public (publishable) and private (secret). Encrypt with recipient's public key; only their private key decrypts. Sign with sender's private key; anyone verifies with sender's public key. غير متماثل: زوج مفاتيح — عام (قابل للنشر) و خاص (سري). تشفّر بمفتاح المستلم العام؛ خاصه فقط يفك التشفير. توقّع بخاص المرسل؛ الجميع يتحقق بالعام.

Block cipher (AES): encrypts fixed-size blocks (128 bits for AES) with modes (CBC, GCM). Stream cipher generates keystream XORed with data bit/byte-by-byte (legacy RC4; ChaCha20 today). تشفير الكتلة (AES): يشفّر كتلاً ثابتة (128 بت لـ AES) بأوضاع (CBC، GCM). تشفير التيار يولّد تيار مفتاح يُعمل معه XOR بت/بايت تلو الآخر.

NONCE (number used once): unpredictable value used once per session/message to stop replay attacks and to derive unique IVs/keys in protocols. NONCE (رقم يُستخدم مرة واحدة): قيمة غير متوقعة تُستخدم مرة لكل جلسة/رسالة لمنع إعادة التشغيل ولاشتقاق IV/مفاتيح فريدة.

4. AES, TRNG, hash functions, SHA, concatenation, RSA signatures, tag types, MAC 4. AES و TRNG ودوال الهاش و SHA والربط وتوقيع RSA وأنواع العلامات و MAC

AES key sizes: 128, 192, or 256 bits. Rounds: 10 (128-bit key), 12 (192-bit), 14 (256-bit). Each round: SubBytes (S-box), ShiftRows, MixColumns (skipped last round), AddRoundKey (XOR round key). Initial AddRoundKey before rounds. أطوال مفاتيح AES: 128 أو 192 أو 256 بت. الجولات: 10 أو 12 أو 14. كل جولة: SubBytes، ShiftRows، MixColumns (ما عدا الأخيرة)، AddRoundKey. جولة AddRoundKey أولية قبل الجولات.

TRNG (True Random Number Generator): entropy from physical noise — used for keys, salts, nonces when prediction must be impossible. PRNG is deterministic from a seed (use seed from TRNG when possible). TRNG: عشوائية من ضوضاء فيزيائية — لمفاتيح وملح و NONCE عندما يجب ألا يُتوقع. PRNG حتمي من بذرة (يفضل بذرة من TRNG).

Hash output: Fixed-length digest; one-way; preimage and collision resistance. Used for integrity, password storage (with salt), and building MACs/signatures. مخرج الهاش: ملخص بطول ثابت؛ اتجاه واحد؛ مقاومة أصلية وتصادم. للتكامل وتخزين كلمات المرور (مع ملح) وبناء MAC والتوقيعات.

Concatenation (∥): H(M ∥ N) hashes message M followed by N — order matters; protocols specify exact layout to avoid ambiguity attacks. الربط (∥): H(M ∥ N) يهشِّر M ثم N — الترتيب مهم؛ البروتوكولات تحدد التنسيق لتجنب هجمات الغموض.

SHA: SHA-1 (160-bit, weak), SHA-2 family (SHA-256 widely used), SHA-3 (sponge). Prefer SHA-256 or stronger today. SHA: SHA-1 (160 بت، ضعيف)، عائلة SHA-2 (SHA-256 شائع)، SHA-3. يفضل SHA-256 أو أقوى اليوم.

RSA digital signature: Hash message → sign digest with sender's private key → verifier decrypts with sender's public key and compares. Provides integrity, authenticity, non-repudiation. توقيع RSA: هاش الرسالة → وقع الملخص بالمفتاح الخاص → المتحقق يفك بالمفتاح العام ويقارن. يوفر تكامل وأصالة وعدم إنكار.

Tag types: (1) MAC tag (e.g., HMAC) — symmetric keyed tag; (2) AEAD authentication tag (e.g., GCM) — verifies ciphertext integrity; (3) Digital signature — asymmetric tag on a hash. أنواع العلامات: (1) علامة MAC (مثل HMAC) — متماثلة بمفتاح؛ (2) علامة AEAD (مثل GCM) لتكامل النص المشفر؛ (3) توقيع رقمي — علامة غير متماثلة على الهاش.

MAC (Message Authentication Code): Keyed function ensuring message integrity + authenticity between parties sharing K (HMAC-SHA256). Different from network MAC address. MAC: دالة بمفتاح تضمن تكامل الرسالة وأصالتها بين طرفين يتشاركان K (HMAC-SHA256). مختلف عن عنوان MAC للشبكة.

5. PKI, TLS, and SSH 5. PKI و TLS و SSH

PKI (Public Key Infrastructure): System of CAs, certificates (X.509), certificate revocation, and trust stores that bind names to public keys. Enables verifying TLS servers and signing emails/code. PKI: نظام جهات مصدرة وشهادات (X.509) وإبطال ومخازن ثقة تربط الأسماء بالمفاتيح العامة. يمكّن التحقق من خوادم TLS وتوقيع البريد والبرمجيات.

TLS (Transport Layer Security): Protocol that provides confidentiality and integrity on a transport connection (usually TCP). Handshake negotiates cipher suite, authenticates server (client optional), derives session keys. TLS 1.2/1.3 — successor to SSL. Used by HTTPS. TLS: بروتوكول يوفر سرية وتكامل على اتصال نقل (غالباً TCP). المصافحة تتفاوض على التشفير وتصادق الخادم وتشتق مفاتيح الجلسة. TLS 1.2/1.3 — خلف SSL. يُستخدم في HTTPS.

SSH (Secure Shell): Encrypts remote login, command execution, and file copy (SCP/SFTP) over insecure networks. Replaces telnet/rsh. Server authentication via host keys; user auth via password or public key. SSH: يشفّر الدخول البعيد وتنفيذ الأوامر ونسخ الملفات (SCP/SFTP) عبر شبكات غير آمنة. يحل محل telnet. مصادقة الخادم بمفاتيح مضيف؛ المستخدم بكلمة مرور أو مفتاح عام.

6. IPv4 address, network address, and subnet mask 6. عنوان IPv4 وعنوان الشبكة وقناع الشبكة

An IPv4 address is 32 bits, often written dotted-decimal (e.g., 192.168.10.45). A subnet mask (or prefix length /n) separates network bits from host bits. Example mask 255.255.255.0 = /24 → first 24 bits are network, last 8 are host. عنوان IPv4 32 بت، يُكتب عادةً عشرياً مقطّعاً. قناع الشبكة (أو البادئة /n) يفصل بتات الشبكة عن المضيف. مثال 255.255.255.0 = /24 → أول 24 بت شبكة، آخر 8 مضيف.

Network address = IP bitwise AND mask (host bits all 0). Broadcast = host bits all 1. Usable hosts ≈ 2host bits − 2 (classic LAN, excluding network/broadcast). عنوان الشبكة = IP مع AND للقناع (بتات المضيف أصفار). البث = بتات المضيف كلها 1. المضيفات القابلة للاستخدام ≈ 2بتات المضيف − 2.

Security link: correct subnetting limits broadcast domains and supports firewall rules (allow/deny by network segment). الربط الأمني: التجزئة الصحيحة تحد من نطاقات البث وتدعم قواعد الجدار الناري (سماح/منع حسب الشبكة).
